# Roadmap de Appartamentos (en vivo)

Mapa interactivo del roadmap: 63 funciones por etapa, con su estado
(hecho / parcial / pendiente) y su criterio de aceptación.

Este repo es una **copia saneada**: sin enlaces a Drive, sin teléfonos y sin
datos societarios. La fuente está fuera de git; `python sync.py` la sanea y
la publica (`--watch` lo repite al cambiar el origen).
